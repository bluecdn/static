使用说明

面向站点开发者与内容创作者，所有资源均可通过 HTTPS 直链引用。

  • 加速体验 — 全球访问目标 100ms 内响应，针对中国网络路径优化，境内外均可流畅加载字体与图标。
  • 如何接入 — 点击资源旁的复制按钮，将链接写入 <link rel="stylesheet"> 或 CSS @font-face，无需注册或 API Key。
  • 跨域使用 — 已开启 CORS，博客、文档站、静态页面与前端应用均可直接引用。
  • 缓存建议 — 字体文件（woff2）适合长期缓存；样式表入口可能随版本更新，更新资源后请刷新 CDN / 浏览器缓存。
  • 图标用法 — 引入 FontAwesome 样式表后，在 HTML 中使用类名，例如：<i class="fa-sharp fa-light fa-house"></i>
  • 许可说明 — FontAwesome Pro 与各字体遵循其原作者许可，商用前请自行确认授权范围。
